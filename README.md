# estilos-csl

Estilo CSL **APA 7.ª edición en español** para Mendeley y Zotero.

- La "y" va solo antes del último autor y sin coma antes: `Byrne, E. M., Jensen, H., Thomsen, B. S. y Ramchandani, P. G. (2023).`
- Términos en español: "Artículo", "2.ª ed.", "s. f.", "En".
- Rango de páginas con guion largo (9–38).

Está basado en el estilo APA 7 oficial del repositorio de estilos CSL (https://github.com/citation-style-language/styles), publicado con licencia CC BY-SA 3.0.

## Instalar en Mendeley Cite (Word)

Citation Settings → Change citation style → Add a custom style → pegar este enlace:

https://raw.githubusercontent.com/elderneingbernedo-hash/estilos-csl/main/apa-7-espanol-y-sin-coma.csl
